# MintyWM Status

A panel indicator for the **MintyWM** tiling extension (a separate download).
**Requires the MintyWM extension to be installed and enabled.**
By Lee Matthew Jackson - leematthewjackson.com - @leematthewjackson@mastodon.social

Shows whether tiling is on, with a different icon for paused-everywhere and off-on-this-workspace. The number is how many windows are tiled; `3+1` means one window did not fit and was parked on screen. Click to open controls and the live key list. Middle-click toggles tiling for that workspace only. Right-click still has the quick actions, including the cheat sheet.

Install: copy this folder to `~/.local/share/cinnamon/applets/`, then add **MintyWM Status**
under System Settings > Applets (or right-click the panel > Applets).
