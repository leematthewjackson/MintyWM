# MintyWM Status

A panel indicator for the **MintyWM** tiling extension (a separate download).
**Requires the MintyWM extension to be installed and enabled.**
By Lee Matthew Jackson - leematthewjackson.com - @leematthewjackson@mastodon.social

Shows whether tiling is on for the workspace you are on, and how many windows are tiled. Click to pause or resume tiling everywhere; middle-click to turn it on or off for that workspace only. The right-click menu has both, plus Re-tile now and Reset tile sizes on this workspace. In the applet settings you can choose a symbolic (theme-matching) or full-colour panel icon.

Install: copy this folder to `~/.local/share/cinnamon/applets/`, then add **MintyWM Status**
under System Settings > Applets (or right-click the panel > Applets).
